Navigation without GPS

01

Co-developed a pedestrian-navigation system that combines smartphone motion sensors and camera data to track movement and reconstruct a 3D path without GPS.

Final project Python Signal processing Sensor data Computer vision
How it works

The system combines accelerometer, gyroscope, barometer, and camera data to identify steps and movement types. Optical flow helps distinguish forward and backward motion, while pressure changes support stair and elevator detection.

A Python application processes the incoming data and displays the reconstructed route. In one mixed-route test documented in our report, 29 of 30 movements were classified correctly.

Team project with Rabeea Bulbul. The linked project book is the current draft and may be updated.

Medical image processing & pattern recognition

02

A collection of Python exercises exploring how images are processed, segmented, and classified—from detecting edges and counting objects to brain-image segmentation and handwritten-digit recognition.

Python NumPy OpenCV Image segmentation Pattern recognition
Explore the exercises
  • Brain-image segmentation

    Clustered grayscale pixel intensities with K-means, comparing 3, 4, and 5 clusters. Applied morphological opening, closing, and connected-component analysis to isolate a candidate bright region.

  • Object counting in noisy images

    Built a processing pipeline using Otsu thresholding, median filtering, boundary extraction, flood-fill, and 8-connected component labelling.

  • Handwritten-digit classification with KNN

    Implemented a K-nearest-neighbours classifier in NumPy for MNIST and compared how different values of K affect classification accuracy.

  • Image basics, edge and coin detection

    Explored resizing, grayscale conversion, rotation, Sobel and Laplacian filters, Canny edges, and the Hough circle transform to detect and measure coins.

  • A sigmoid neuron from scratch

    Implemented a forward pass, mean squared error, manually derived gradients, and gradient descent in NumPy to understand the training process.

VLSI: registered arithmetic unit

04

Worked on a digital arithmetic unit in Cadence Virtuoso, combining registers and Kogge–Stone adders to compute X = A + B and Y = X − C from signed 4-bit inputs.

VLSI Cadence Virtuoso CMOS 45 nm Digital design
Design approach

The design uses a 4-bit adder for the first sum and a 5-bit adder for subtraction through two’s-complement arithmetic, with 5-bit intermediate and output registers.

The workflow covered schematic design, simulation, layout, and DRC/LVS checks to investigate physical-design and connectivity issues.

Deep learning: hybrid branch prediction

05

Co-developed a branch predictor that pairs a lightweight neural network with a Transformer, directing uncertain cases to the larger model to balance prediction accuracy and model usage.

Python PyTorch MLP Transformer Model evaluation
Approach & results

Evaluated the hybrid approach on 300,000 branch events from SPEC CPU2006 traces, using a chronological training, validation, and test split.

The hybrid achieved 95.40% test accuracy, compared with 93.91% for the lightweight model alone. The Transformer handled 16.7% of predictions.

Team project with Kareem Bwakny and Rabeea Bulbul.
